以下设置只影响桌面外壳，不改动 DSH 本体及其数据。

关闭后应用不再启动本地服务，窗口只显示本设置页；再次启用即恢复。

0 = 自动选择空闲端口（默认，推荐）。固定端口时请避开已占用的端口—— 例如原版 DSH / 其他实例正在使用的 3080，保存时会自动检测并提示。

启动后自动检查并下载新版本（下次启动生效）。关闭后仍可在下方手动"检查更新"。

关于局域网访问：上游 DSH 出于安全原因明确拒绝把服务绑定到局域网 （--host 0.0.0.0 会报 "intentionally not supported yet for safety"， 因为它等于把可执行任意命令的 agent 暴露到网络）。桌面版遵守同一立场，不提供绕过。 需要远程访问时，请使用 SSH 隧道（认证加密，流量仍是回环）：
ssh -L 127.0.0.1:<端口>:127.0.0.1:<端口> 用户@主机
配合上方"固定端口"即可稳定连接。
